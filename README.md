# Lab8_CRUD 
Простое Windows Forms приложение для работы со списком студентов.

## Функционал 
- Добавление новых записей.
- Редактирование существующих.
- Удаление записей.
- Поиск по ФИО.
- Экспорт данных в CSV-файл.

## Как запустить 
1. Скачайте проект.
2. Откройте файл `Lab8_CRUD.sln` в Visual Studio. 
3. Нажмите F5 для запуска.
